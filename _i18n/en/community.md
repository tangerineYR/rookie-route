# Rookie Route Community

Rookie Route was developed using an open-source collaboration workflow.

The repository preserves the collaboration structure used during the project,
including Issues, branches, Pull Requests, documentation, and contribution
guidelines.

## 🤝 Collaboration Resources

Project collaboration resources include:

- GitHub repository history
- Pull Requests
- Issues
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- Korean / English documentation

## 🌱 Open-source Development Experience

The project used an Issue → Branch → Commit → Pull Request → Review workflow.

Documentation was also managed as code through Sphinx, ReadTheDocs, Jekyll,
and GitHub Actions.

## 📌 Current Scope

This page preserves the project's open-source collaboration structure.

It does not imply that separate real-time mentorship programs, 1:1 mentoring,
or an actively staffed community service are currently being operated.
