# Rookie Route Community

Rookie Route는 Open Source Collaboration Workflow를 기반으로 개발한 팀 프로젝트입니다.

Repository에는 프로젝트 당시 사용한 Issue, Branch, Pull Request,
Documentation 및 Contribution Guide가 보존되어 있습니다.

## 🤝 협업 자료

프로젝트의 협업 과정은 다음 자료에서 확인할 수 있습니다.

- GitHub Repository History
- Pull Requests
- Issues
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- 한국어 / 영어 Documentation

## 🌱 Open Source 개발 경험

프로젝트에서는 다음 협업 흐름을 사용했습니다.

```text
Issue
  ↓
Branch
  ↓
Commit
  ↓
Pull Request
  ↓
Review
```

Documentation 역시 Sphinx, ReadTheDocs, Jekyll, GitHub Actions를 활용해
Docs as Code 형태로 관리했습니다.

## 📌 현재 범위

이 페이지는 프로젝트 당시의 Open Source 협업 구조를 보존하기 위한 문서입니다.

현재 별도의 1:1 멘토링 프로그램이나 상시 운영되는 실시간 커뮤니티 서비스를
제공하고 있음을 의미하지 않습니다.
